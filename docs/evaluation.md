# 验收与已知范围

## 自动检查

运行 `python -m unittest discover -s tests -v` 验证个人配置错误被拒绝、已有配置不被覆盖，以及 ZIP 排除本地个人资料。运行系统 skill-creator 的 quick_validate 检查两个技能的前言和占位。检查相对引用在整个 Plugin 内均能解析。

这些检查不证明模型每次都会自动触发，也不替代真实 Notion 读写与 Plugin 导入。

## 真实行为验收

| 场景 | 应观察到的行为 |
| --- | --- |
| 新用户首次安装 | 请求其主页/新建位置与同步偏好；不写作者账号 |
| 自己已有 Homepage | fetch 后保留原结构，准确识别 Projects 位置 |
| 新项目已允许建页 | 查重、建在自己的主页下、添加入口、回读 |
| 确定决策 | 更新项目日志与必要知识，回复含真实目标链接 |
| 同一决策再提出 | 不重复追加日志 |
| 仅建议未接受 | 保留为待决定，不写成确定决策 |
| 建页成功补入口失败 | 重试只补入口，不建第二页 |
| 同名项目或账号切换 | 核对当前用户目标，不沿用其他账号映射 |
| 主页排版 | 保留分栏、子页、数据库、同步块及附件 |
| 用户要求归档 | 更新导航与状态，保留历史；不自动删除 |
| 只读/断连 | 报告具体缺失能力，保留待同步内容 |
| 云端新会话 | 实际技能可选、Notion 已授权、个人配置可读取 |
| 学习与项目执行切换 | 按需讲解/练习；要求直接答案或完成项目时立即调整 |
| 用户自述已懂但未练习 | 记录自述或已讲解，不标记独立掌握 |
| 学习模式但仅授权决策记录 | 不自动保存无关学习聊天 |
| 同一知识点多轮问答 | 在节点更新同一主题，不每轮建页 |
| 学习记录与导师技能组合 | 一个流程负责写入，避免重复笔记 |
| 复习旧主题 | 读取真实笔记与薄弱点，不编造历史表现或提醒任务 |
| 聊天同时有知识与项目 | Learning 和 Projects 分别可达，正文互相引用而非整篇复制 |
| 总结当前聊天 | 来源范围明确，建议与决定区分，读已有记录后合并 |
| 指定历史材料补录 | 仅处理选定范围；日期、截断和未读取缺口真实报告 |
| 用户跳过历史整理 | 不反复提示，不扩大为扫描整个账号 |

## 当前验证状态

此前的个人版已实际执行主页搜索、读取、项目记录更新与主页入口回读。本次通用版本会在现有账号中再次记录本次决策和使用文档。尚未在第二位用户账号、ChatGPT 网页安装、Plugin 平台导入/审核或所有异常场景进行实测；不得将这些标为通过。

0.3.0 增加学习参考流程与上述验收场景。分发与技能格式检查继续执行；尚未完成真实学习者的多轮教学、练习评分及后续复习验收。这些行为场景是后续验证目标，不是已通过的测试。
