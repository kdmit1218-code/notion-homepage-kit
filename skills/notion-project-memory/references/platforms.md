# 运行平台与连接边界

本地 Codex：安装技能文件夹，配置 profile.local.json，使用现有 Notion 连接。`$notion-project-memory` 显式启用。包中脚本只能在有文件系统和 Python 的环境执行。

ChatGPT：使用支持的 Skill/Plugin 安装流程，安装后新开聊天，通过 `@` 选择技能；连接该使用者自己的 Notion。个人配置来自用户给定的主页/配置页，而不是读取作者电脑路径。支持范围及权限以当前账号和平台官方界面为准。

本地安装不自动成为云端安装；上传一个 Markdown 作为普通附件也不能被描述为已安装技能或已获得 Notion 写入能力。说明、实际 Notion 工具、个人配置缺一不可。

API：可用官方 Skills API 与支持 skills 的工具环境；另配置 MCP/工具连接与该用户授权。API 项目和 ChatGPT 插件安装是不同流程。没有部署请求不上传、不创建远程服务器或产生 API 调用费用。

公共包只提供方法与模板。连接器的 OAuth 与平台审批仍然有效，技能不能绕过它们。不承诺全账号所有聊天自动记录或关掉聊天后继续监听。
