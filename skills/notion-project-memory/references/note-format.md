# 项目页与决策格式

已有页沿用合适的结构，新页采用以下模块，有内容才展开。

## 项目概览

目标、当前状态、最新方案和真实产物链接。区分已完成、进行中与待验证。

## 决策日志

三级标题“日期｜议题”，正文为结论、理由（必要时含替代方案）、影响与下一步。日期使用当前会话与配置时区。简单决策可一段写完；比较方案时才用表格。

## 可复用知识

按主题整理概念、方法、复现步骤、技术条件和来源。代码加语言标签；长细节放 toggle，关键结论保持可见。不逐条复制聊天、不填造负责人、测试通过或不存在的文件链接。

## 待办与待决定

只记录实际存在的事项，无期限不虚构。用户自己的想法、资料中的事实、助手推断分别表述；尚未同意的建议保留为待决定。
